WP Kandoo Mobile is a mobile experience builder for WordPress with a live phone preview, mobile overrides, custom mobile header and bottom navigation.

== Features ==
* Live website preview inside a phone frame.
* Page switching.
* Multiple phone sizes and landscape mode.
* Mobile breakpoint control.
* Mobile-only CSS.
* Selector-based element hiding.
* Custom mobile header.
* Sticky header option.
* Custom mobile bottom navigation.
* Settings are preserved during updates.
* RTL-ready Kandoo admin UI.

== Installation ==
Upload the wp-kandoo-mobile folder to wp-content/plugins/ and activate it from WordPress.

== Notes ==
The first release focuses on the core mobile experience engine and live preview. Future releases can add deeper integrations for Elementor, Gutenberg, WooCommerce, theme builders, visual element inspection and media controls.
